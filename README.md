# Security Tools

Python security tools built from scratch.

| Tool | Description |
|---|---|
| blind_sqli_extractor.py | Boolean-based blind SQLi password extractor |
| Network_scanner.py | Network Scanner for find devices connected to the same network |
| arp_spoofer.py | ARP spoofing tool using Scapy |
| packet_sniffer.py | HTTP credential sniffer |
| mac_changer.py | MAC address changer |
